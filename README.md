# Dr Cloud Social Agent — V1

## Démarrage
1. Installe Node.js 20+.
2. Dans ce dossier : `npm install`
3. Copie `.env.example` vers `.env.local`.
4. Mets ta clé OpenAI dans `.env.local` (ne la publie jamais).
5. Lance `npm run dev` puis ouvre http://localhost:3000.

## V1
- Interface mobile
- Génération de contenu via OpenAI côté serveur
- Base pour validation/calendrier/produits
